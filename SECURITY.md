# Security policy

Report vulnerabilities in vmware-vm-control privately through GitHub: repository > **Security** > **Report a vulnerability**. If that is not available to you, open an issue without exploit details and ask for a private contact.

Reports are acknowledged and investigated with reasonable care; fixes are released as a new version (see CHANGELOG.md). Only the latest release is supported.

What the plugin stores and sends is described in [plugins/vmware-vm-control/README.md#data-and-network](plugins/vmware-vm-control/README.md#data-and-network).
